# PFE 2026.2 · AP1 · Grupo 4 (terça)

Plataforma digital da **PKZ (Play Makerz)** e da **One to One**: um site institucional com uma página inicial comum às duas marcas (Hub) e uma landing page para cada uma.

Escopo, público e fases do projeto: ver o [Documento de Visão](Doc-visão/DOCUMENTO_DE_VISAO.md).
